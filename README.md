# 小球大战 Ball Battle

参考 Orbitlity「64 小球锦标赛」视频（B 站合集，视频本身不在仓库里）复刻的自动对战小游戏：两个小球在方形竞技场里不停反弹，各自靠特殊能力打掉对方的 100 点血。

技术栈：React 19 + Vite + Tailwind CSS v4 + TypeScript，画面用 Canvas 2D 绘制，音效由 WebAudio 实时合成（没有任何素材文件）。

## 运行

```bash
bun install
bun run dev        # 开发服务器
bun run build      # 类型检查 + 生产构建（输出到 dist/）
bun run deploy     # 构建并部署到 Cloudflare Workers（https://ball.contextudio.com，配置见 wrangler.jsonc）
bun run sim 100    # 无头模拟：每组对局各打 100×2 局，输出胜率和时长
bun run dps        # 各角色在不同时间段的每秒伤害
bun run vsall knight,hive 10   # 指定角色对全体的胜率（调参时用）
```

选角页的规则文字直接引用代码里的数值常量，调参后会自动同步。

对局超过 90 秒进入「加时」，双方持续掉血，保证一定会分出胜负。

### 和原视频不一致的地方（有意为之）

- **列车长**：原作里火车能把敌人一路拖着碾（实测单班最高约 -60），模拟里出现过单班 -150 的情况。改为每班车最多命中 3 次，同时让下一条铁轨提前开铺，用稳定输出代替一击秒杀。
- **鱼钩**：原作只有甩动，命中率太低；加了「抛竿 + 回拽」。
- **手榴弹**：原作看起来没有瞄准，但按原作的伤害反推命中率约 35%，随机散布只有 5%，所以改为带提前量的抛掷。
- **象棋**：原作随机抽棋子、整个棋盘阶段无敌；这里改为挑最合适的棋子、只在冲刺阶段无敌，避免对局拖进加时。
- **激光 V2 / V3、强酸**：原作的线、炮台、酸液都没有上限，在我们的场地比例下会铺满全场，所以都加了数量上限；强酸的腐蚀改为挂在敌人身上的状态（多滩叠加最多 2 倍）。
- **五条悟**：原作每隔 5 秒出现的圆环没有任何可观察的效果，没有实现。
- **黑洞**：只实现了 V1；V2 的伤害和引力规则从视频里无法确定。
- **召唤物**（复制者的分身、死灵巫师的骷髅、蜂巢的蜜蜂等）：引擎里只有两个球能被攻击，所以召唤物都不可被攻击，改为有存活时间。
- **骑士**：原作举盾期间完全免疫，保留；但举盾时间缩短为 1.5~3 秒（持剑 2~8 秒）、剑伤 -10 → -6、剑长 4.6R → 3.8R，否则胜率高达 95%。
- **模仿者**：每次变身都会重置所借能力的冷却和成长，平均只能发挥原角色约 65% 的输出，所以变身期间伤害 ×1.5（引擎的「输出伤害倍率」钩子，余数会结转到下一击，小伤害也能按比例加成）。
- **铁刺**：原作自己碰到钢刺和敌人一样掉血，按原规则胜率只有 3%；改为自己碰到只 -1，敌人 -5。
- **大炮、星陨**：原作看起来是瞄准当前位置，但炮弹/陨石很慢，几乎打不中移动目标；改为按敌人的反弹路线预判瞄准。
- **电钻**：原作钻完后电钻会向后弹开，按这个规则贴身型角色（吸血鬼、病毒、雷电……）几乎永远碰不到电钻，胜率是 0%。改为钻的时候两球锁在一起、钻完各自恢复原来的运动方向：原本相向而来的两球会撞上，这时电钻还在冷却，贴身角色可以反击。冷却相应缩短为 1.6 秒。
- **蜘蛛**：原作被网住的敌人头顶有缴械图标，按「网住期间缴械」实现（之前的版本里被网住的敌人照样能出招，蜘蛛胜率垫底、对 21 个角色低于 20%）。
- **缴械的统一规则**：缴械期间不能发起新的攻击，已经放出去的东西（飞行中的弹体、地上的陷阱、已召唤的小兵）照样有效；拿在手里/绕身转的武器（铁锯、刺客、骑士、锤神、回旋镖）不伤人。病毒的接触传染是它的设定，不受缴械影响。
- **其余角色**：机制按视频还原，伤害/间隔等数值为了平衡做过调整（见下文）。

视频里出现过的角色已经全部实现。

## 操作

- `空格` 暂停 / 继续 · `1`–`4` 切换 0.5x / 1x / 2x / 4x 速度
- `R` 用同一个种子重播 · `N` 换新种子再战 · `M` 静音 · `Esc` 返回选角

模拟使用固定步长（120Hz）和可设定种子的随机数，所以相同的角色 + 种子必定得到完全相同的对局。

## 代码结构

```
src/game/
  core/          向量、几何（线段/旋转矩形/三角形碰撞、按弧长取样的折线）、随机数
  engine/        World（物理、伤害、中毒/减速状态、阶段与加时）、Ball、Ability 基类、粒子与飘字
  characters/    64 个角色的能力实现 + registry（名称、配色、规则文字）；minions.ts 是召唤物共用的追踪群
  render/        Canvas 渲染器与共用绘图函数（铁轨、火车、毒刺、抓钩……）
  audio/         合成音效
  BattleController.ts   游戏循环，通过 useSyncExternalStore 把血量等数据推给 React
src/components/  选角页、对战页、结算面板
scripts/         平衡性模拟脚本
```

新增角色：在 `characters/` 里继承 `Ability`，按需实现 `onWallBounce` / `onBallContact` / `update` 和对应的 `render*` 钩子，再到 `registry.ts` 注册，并在 `engine/types.ts` 的 `CharacterId` 里加上 id。如果有新的伤害类型，在 `DamageKind` 里加上它，并在 `engine/hitEffects.ts` 里配好命中特效和音效。发动新攻击前要检查 `owner.disarmed`（锤神的缴械），否则缴械对它不起作用。

## 平衡性

`bun run sim 16` 会把所有组合（64 个角色，2016 组）各打 32 局。目前 64 个角色的总胜率都在 41%–59% 之间，对局时长中位数约 37 秒（10%–90% 分位 27–53 秒），与原视频接近。`bun run dps 6 角色id,角色id` 可以只测指定角色的输出曲线，`bun run vsall 角色id 10` 可以快速看单个角色调参后的胜率。

只靠身体碰撞输出的角色（铁锯 V2、病毒、仙人掌等）天生碰撞频率低，所以单次伤害给得比较高；叠层/成长型角色（毒刺、蜘蛛网、长矛、激光 V3）前期弱、后期强，这是角色特色。

有几组是机制上的硬克制，属于角色定位，没有特殊处理：

- **锤神 克制 吸血鬼**：吸血鬼要贴身才能咬，而旋转的锤子会持续惩罚靠近，被砸中还会缴械。
- **电钻 克制 青蛙**：青蛙要把猎物拖到嘴边，等于把电钻送到自己脸上。
- **吸血鬼 克制 雷电**：被咬住后两球连在一起，不会再发生新的碰撞，雷电没法再次放电。
- **蜘蛛 克制 毒刺、列车长**：这两个角色靠撞墙发动能力，被定身时什么都做不了。
